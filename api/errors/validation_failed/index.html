Request is not valid

VALIDATION_FAILED, HTTP 422

VALIDATION_FAILED is answered with HTTP status 422.

Part of the request is not valid. Correct what the response names and send it again.

What to do

Correct the value and send it again.

Trying again

Sending the same call again gives the same answer unless something changes first. The retryable field on the response is advice for that one response, so follow it when it differs.

Why you can get it

The response's reason field says which of these applies.

  • time_off_cover_kind: Supply a teammate for person cover only.
  • time_off_dates: Time off must end after it starts.
  • time_off_person: Choose an eligible teammate in that queue other than yourself.
  • time_off_queue: Choose a queue you work in.
  • time_off_window: Choose an end after the start, at most 367 days later.
  • attachment_size: The uploaded file must be at most 50 MiB.
  • unsupported_file: The file type is not supported.
  • unknown_priority: No priority with that name is available to you.
  • unknown_state: No state with that name is available to you.
  • unknown_queue: No queue with that id is available to you.
  • unknown_assignee: No person with that id is available to assign.
  • unknown_requester: No person with that id is available as the requester.
  • unknown_followers: A follower you named is not available.
  • assignee_not_eligible: This person cannot be assigned tickets.
  • operator_not_eligible: This person cannot be added to a queue.
  • unknown_filter_value: A filter names a value that does not exist.
  • unsupported_language: That language is not supported.
  • link_type_ambiguous: More than one link type has that name.
  • cursor_invalid: The cursor is not valid. Start again without one.
  • grant_not_accepted: That access cannot be given to this person or group.
  • grantee_gone: The person or group no longer exists, so there is nothing to take away.
  • cursor_mismatch: The cursor belongs to a different request. Start again without one.
  • blank_value: This value cannot be blank.
  • window_inverted: The end of the window comes before its start.
  • nothing_to_change: The request changes nothing.
  • reason_required: A reason is required.
  • invalid_setting: The setting is not valid.
  • missing: A required value is missing.
  • invalid_value: A value is not valid.
  • steps_not_ticked: A required step of this task has not been ticked.
  • step_unknown: That step is not part of this task.
  • answers_invalid: The answers do not fit what the form asks.
  • answer_not_accepted: The answer does not fit what was asked.
