Permission denied

PERMISSION_DENIED, HTTP 403

PERMISSION_DENIED is answered with HTTP status 403.

Your account cannot take this action. Ask an administrator in your organization for access.

What to do

Ask an organization admin to grant access.

Trying again

Sending the same call again gives the same answer unless something changes first. The retryable field on the response is advice for that one response, so follow it when it differs.

Why you can get it

The response's reason field says which of these applies.

  • state_change: You cannot change the state of this ticket.
  • comment: You cannot comment on this ticket.
  • field_not_editable: You cannot change this field on this ticket.
  • followers_add: You cannot add followers to this ticket.
  • followers_remove_others: You cannot remove other people from this ticket's followers.
  • not_comment_author: Only the author can change this comment.
  • assignee_cannot_nudge: The assignee cannot nudge their own ticket.
  • queue_work_required: You need to work this ticket's queue to do this.
  • person_required: This needs a signed-in person.
  • not_permitted: You do not have the permission this needs.
  • workflow_access_list: You need view, edit or publish access to this workflow to see who has access to it.
  • workflow_access_manage: You need to be able to change who has access to this workflow to do this.
  • workflow_versions: You need view, edit or publish access to this workflow to see its versions.
  • workflow_dependencies: You need access to view this workflow to see what calls it.
  • workflow_run: You need run access to this workflow to see what it asks for or to start it.
  • operators: You cannot see who works this queue.
  • availability: You cannot see operator availability.
  • search_availability: You cannot search by operator availability.
  • change_availability: You cannot change operator availability.
  • queue: You cannot see this queue.
  • search_queues: You cannot search queues.
  • create_queue: You cannot create queues.
  • change_queue: You cannot change this queue.
  • set_default_queue: You cannot set the default queue.
  • change_operators: You cannot change who works this queue.
  • saved_filters: You cannot use saved filters.
  • translations: You cannot use translations.
