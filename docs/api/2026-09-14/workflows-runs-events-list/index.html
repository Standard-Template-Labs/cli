GET List what happened in a run

/runs/{run}/events

The steps of a run as they started, finished, failed or stalled, oldest first, paged with a cursor. A run you cannot see, and a run of a single action, is reported as not found. What each step was given and produced is not shown.

Parameters

NameInTypeRequiredDescription
runpathstringyesThe run's id.
cursorquerystringWhere the next page starts: the next_cursor the previous page returned.
limitqueryintegerHow many results to return. At most 500.

Response 200

FieldTypeRequiredDescription
itemslist of objectyesThis page of results.
next_cursorstring, or nullPass as cursor to fetch the next page. null on the last page.

Errors

A failed call answers with a problem body: a stable code to branch on, a detail for people, and retryable, which is advice for that one response.
