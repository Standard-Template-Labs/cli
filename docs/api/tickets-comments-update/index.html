PATCH Change a comment you wrote

/tickets/{ticket}/comments/{comment}

Replace the text of a comment you posted, by the id the ticket's comments give. Only the person who wrote a comment can change it.

Parameters

NameInTypeRequiredDescription
ticketpathstringyesThe ticket id people see in the product, such as ACME-042.
commentpathstringyesThe comment's id, as the ticket's comments give it.

Request body

What changing a comment accepts.

FieldTypeRequiredDescription
bodystringyesThe new comment text, in plain text. It replaces the old text.

Response 200

FieldTypeRequiredDescription
authorobjectyesWho wrote it.
bodystringyesThe comment text, in plain text.
created_atstring (date-time)yesWhen it was posted.
edited_atstring (date-time), or nullWhen the comment was last edited; null if never.
idstringyesUnique within this ticket; unchanged when the comment is edited.
visibilityalways publicyesOnly public comments are returned.
