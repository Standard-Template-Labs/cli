Versions

How the command line and the API are versioned.

  • The command line is versioned by semantic versioning; the API is versioned by date. They move for different reasons and never force each other.
  • Every build is made from one API version and sends it on every call. A build keeps working on its API version until that version is retired. New commands come with a new build.
  • A change to the commands, flags, environment variables, config path or exit codes is a major version. New commands from an additive API change are a minor version. A fix is a patch.
  • Before 1.0 nothing above is a promise: the surface can still change between releases.
  • stlabs --version prints the build's version and its API version.
